# 囤货管家

一款轻量的家庭囤货管理 Web App，帮助你记录食品、药品、日用品的数量、生产日期和保质期，到期自动提醒，再也不怕东西放过期了。

## 主要功能

### 📦 物品管理
- 记录每样物品的**名称、数量、生产日期、保质期至、放置位置、备注**
- 按分类分组展示，支持折叠/展开
- 颜色状态标记：绿色（新鲜）、黄色（临期）、红色（已过期）
- 搜索功能 + 分类筛选

### 📂 自定义分类
- 预置分类：食品、药品、日用品
- 支持添加、编辑、删除分类
- 每个分类可独立设置**提前提醒天数**（如食品提前7天、药品提前30天）
- 可自定义分类颜色

### 📍 自定义位置
- 预置位置：冰箱冷藏、冰箱冷冻、厨房柜子、卫生间、储物间
- 支持添加、编辑、删除放置位置
- 添加物品时以下拉菜单选择位置

### 🔔 保质期提醒
- 自动检测即将过期和已过期的物品
- 到达提醒日期时自动弹出浏览器通知
- 提醒音提示（三音旋律，无需外部文件）
- 每日只提醒一次，避免重复打扰

### 📱 移动端适配
- 响应式设计，手机、平板、电脑均可使用
- 支持「添加到主屏幕」，全屏运行如同原生 App
- 底部导航栏，触摸友好的大按钮

### 💾 数据管理
- 数据自动保存在浏览器本地（localStorage）
- 支持一键导出数据（JSON 备份）
- 支持导入数据恢复

## 安装方法

### 方式一：直接使用（推荐）

在手机浏览器中打开部署好的网址，然后添加到主屏幕即可。

**iPhone（Safari）：**
1. 用 Safari 打开网址
2. 点底部中间的「分享」按钮
3. 选择「添加到主屏幕」
4. 点「添加」，桌面出现图标

**Android（Chrome）：**
1. 用 Chrome 打开网址
2. 点右上角三个点菜单
3. 选择「添加到主屏幕」或「安装应用」
4. 确认，桌面出现图标

### 方式二：本地使用

1. 下载 `index.html` 文件
2. 用浏览器打开即可使用
3. 建议使用 Chrome 或 Safari 以获得最佳体验

### 方式三：自行部署

将所有文件上传到任意静态托管平台：

- **GitHub Pages**：创建仓库 → 上传文件 → 开启 Pages
- **Netlify**：直接拖拽文件到 netlify.com/drop
- **Vercel**、**Cloudflare Pages** 等均可

## 数据保存和导出

### 数据存储位置

所有数据（物品、分类、位置）存储在**浏览器本地**，不会上传到任何服务器。数据与浏览器绑定，换浏览器或清除浏览数据会导致数据丢失。

### 导出数据（备份）

1. 打开 App，进入「设置」页面
2. 点击「导出数据」按钮
3. 浏览器会自动下载一个 JSON 文件
4. 建议定期导出备份

### 导入数据（恢复）

1. 打开 App，进入「设置」页面
2. 点击「导入数据」按钮
3. 选择之前导出的 JSON 文件
4. 确认后数据将恢复

### 注意事项

- 清除浏览器缓存/数据会丢失所有记录，请先导出备份
- 更换手机或浏览器时，先在旧设备导出，再在新设备导入
- 建议每月导出一次备份
